# Intent API

FastAPI backend for a message-classification service.

## Run locally (Windows PowerShell)

From the project directory:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Create `backend/.env` with your provider credentials and model:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b
```

Do not commit `.env` or share its contents. Start the development server from
the `backend` directory:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

The local API base URL is `http://127.0.0.1:8000`. Stop the server with
**Ctrl+C**.

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/health` | Health check. Returns a status and message. |
| `POST` | `/api/analyze` | Classifies the message provided in the JSON request body. |
| `GET` | `/docs` | Interactive Swagger UI generated by FastAPI. |
| `GET` | `/redoc` | ReDoc API documentation generated by FastAPI. |
| `GET` | `/openapi.json` | OpenAPI schema generated by FastAPI. |

### Health check

```http
GET /health
```

Example response:

```json
{
  "status": "ok",
  "message": "Ingestion Firewall API is running"
}
```

### Analyze a message

```http
POST /api/analyze
Content-Type: application/json
```

Request body:

```json
{
  "message": "Where is my order?"
}
```

On success, the response contains `intent`, `risk_profile`, `priority`,
`requires_action`, `summary`, and `token_metadata` (including
`estimated_input_tokens`). The intent is one of `greeting`, `order_tracking`,
`payment_issue`, `current_time`, `general_question`, or `unknown`.

Example response:

```json
{
  "intent": "order_tracking",
  "risk_profile": "medium",
  "priority": "low",
  "requires_action": true,
  "summary": "Asks about an order.",
  "token_metadata": {
    "estimated_input_tokens": 5,
    "note": "Estimated input token count for the message"
  }
}
```

Invalid request bodies return `422`. Provider or model failures return `502`.
